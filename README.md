# Focal Scan

Focal Scan is an offline Android app for recording animal behaviour during focal observations. It logs timed behaviour events by animal ID, shows cumulative observation time, and exports saved sessions as CSV.

[Download the Android APK (v0.0.1)](https://github.com/wobblytwilliams/focal_scan/releases/download/v0.0.1/focal-scan_v0.0.1.apk)
